galgame 日语助手 v1.1.10
========================================

玩 galgame 时把日语字幕框住，程序自动认出日文 → 译成中文 → 顺手讲清这句话的语法点和生词。
截图与文字识别全在本机（Windows 自带日语 OCR 引擎，不联网）；只有「翻译+讲解」会调用你自己填的大模型接口。

【一、先装日语 OCR 语言包（最重要，只需一次）】

本程序用的是 Windows 自带的 OCR 引擎，你的电脑必须装了「日本語」的 OCR 组件，否则识别不出来。

方式 A（图形界面）
  Win11：设置 → 时间和语言 → 语言和区域 → 添加语言 → 搜「日本語」→ 安装
         → 装好后点它的「语言选项」→ 勾选「光学字符识别（OCR）」
  Win10：设置 → 时间和语言 → 语言 → 添加首选语言 → 日本語
         → 装好后进「选项」→ 勾选「光学字符识别」

方式 B（管理员 PowerShell 一条命令）
  Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"

装完可以验证：在本文件夹打开 PowerShell，执行
  .\galgame日语助手.exe --check
同目录会生成 selfcheck.txt，里面有一行
  OCR 引擎 lang=ja 可用语言=['en-GB', 'ja', 'zh-Hans-CN']
只要「可用语言」里有 ja 就行。

【二、三步上手】

1) 双击 galgame日语助手.exe，打开游戏到有对话的画面
2) 按 F7，只框住「对话框」那一块（不要框整屏，框大了识别会慢好几倍）
3) 打开「设置 → 模型」，填三项：
     base_url  https://api.deepseek.com/v1     （也可以换成任何 OpenAI 兼容地址，本地 Ollama 填 http://127.0.0.1:11434/v1）
     model     deepseek-chat
     api_key   你自己的 key（只保存在本机 config.json，不会上传到别处）
   回到主窗口勾「自动翻译」（或按 F8）→ 就可以玩了。

没填 key 也能用：离线语法库会标出句子里命中的 118 条常用句型，只是没有中文译文。

   想省钱也可以走微软翻译：设置 → 翻译引擎 → 选「微软翻译」，
   填 Azure 翻译器资源的 KEY 1（区域如 eastasia，全球资源留空）。
   这条只给译文、按字符计费（每月免费 200 万字符），语法与生词用本地句型库补。
   两条路随时切换，缓存共用；点「测试微软翻译」能立刻验证通没通。

   点「保存并应用」会当场校验：程序先存盘，再真连一次接口翻一句样例台词。
   - 通了 → 弹「配置已保存并通过校验」，框里就是刚才的真实译文；
   - 没填 key → 弹提示，告诉你现在只有本地句型库、key 该去哪抄（配置照样保存）；
   - 地址/密钥错了 → 弹错误框，正文写着下一步怎么做。
   校验在后台跑，网络慢时只是按钮变灰、底部显示「正在校验配置…」，窗口不会卡死。

【三、热键】

  F7   框选字幕区域
  F8   自动模式 开/关
  F9   立即翻译一次
  F10  悬浮字幕 显示/隐藏
  F6   悬浮字幕 鼠标穿透 开/关（穿透后按住 Ctrl 仍能拖动）

  悬浮字幕条：拖动=移动（位置会记住），滚轮=改字号，右键=菜单（位置重置 / 设置 / 隐藏）

【四、配置在哪】

优先使用 exe 同目录的 config.json（首次运行自动生成）。
如果 exe 所在目录不能写入（例如放在 C:\Program Files），会自动改存到：
  %LOCALAPPDATA%\galtl\config.json
--check 的输出里会写明实际路径。

【五、常见问题】

· Windows 提示「已保护你的电脑」/ 杀软报毒
    单文件 PyInstaller 程序的常见误报，点「更多信息 → 仍要运行」，或把 exe 加入白名单。

· 一直显示「等待台词…」/ 认不出字
    框选区偏了，或游戏是独占全屏（改成「无边框窗口」）。重按 F7 只框文字区；
    设置里把 min_ratio 调到 0.2；白字发虚就开 binarize，upscale 调到 2.5。

· 译文和原文对不上 / 老翻同一句
    设置里 stable_reads 调到 2~3（2 最快），poll_ms 默认 250 就够，卡就调大到 400。

· 一帧要好几秒
    region 框太大了。整屏一帧要 1.5~3 秒，1300×300 的对话框约 0.2 秒。
    1.0.6 起画面没变化时只比一次缩略图指纹（约 50ms）就跳过识别，所以真正花时间的只有「新台词」那一帧。
    如果状态栏提示「这一帧识别花了 xxx ms」，就按 F7 把框缩小到对话框文字区。

· 模型报 401
    api_key 或 base_url 不对（base_url 要以 /v1 结尾）。设置里有「测试连接」会显示原始报错。

· 双击没反应
    在文件夹里执行 .\galgame日语助手.exe --check，看同目录 selfcheck.txt 和 galtl.log（UTF-8 文本，1MB 自动轮转）。

【六、隐私】

· 截图只在内存里交给本机 OCR 进程，不落盘、不联网。
· 只有「识别出的日文 + 少量上下文 + 你的术语表」会发给你配置的模型接口。
· api_key 只写在本机 config.json；历史与缓存是不含 key 的 cache.db。

【五、覆盖原文（把中文直接盖在日文台词上）】

F11 开关。开启后中文会出现在日文原来的位置，看上去像官方中文版：

  * 覆盖层是「内嵌」在游戏窗口里的——游戏被点一下、切全屏都压不掉它；
    游戏挪窗口、改大小、最小化，它都会跟着走、跟着收、跟着回来。
  * 它自己也看不见自己：覆盖层对截屏不可见，识别不会读到中文。
  * 想改底色/透明度/字号，在「设置 → 显示」里调；
    用 NVIDIA 或 OBS 录屏、又想在视频里看到中文，把「截图可见性」改成 record。
  * 位置要重新框的时候按 F7，只框文字那一带即可。
